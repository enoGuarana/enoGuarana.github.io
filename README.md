# João Victor Rikio Enomoto - Portfolio

Static portfolio built for GitHub Pages.

## Publish on GitHub Pages

1. Create a public repository named `joaoenomoto.github.io`.
2. Push these files to the repository root.
3. In GitHub, open `Settings > Pages`.
4. Select `Deploy from a branch`, branch `main`, folder `/root`.

The site will be available at:

```text
https://joaoenomoto.github.io
```

## Local preview

Open `index.html` in a browser or serve the folder with any static server.
